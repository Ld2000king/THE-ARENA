# הזירה

משחק קלפים של קרבות מפלצות, בהשראת משחק "מלחמה". לכל צד חפיסה של 20 קלפים, לכל קלף מפלצת מצוירת, רמת כוח ויכולת מיוחדת.

## הפעלה

אין צורך בהתקנה או בבנייה — לחיצה כפולה על `index.html` מפעילה את המשחק בדפדפן.

לחלופין, להרצה דרך שרת מקומי:

```
node serve.js
```

ואז לפתוח את http://localhost:5177

## חוקי המשחק

1. לכל צד חפיסה של **20 קלפי מפלצות**.
2. בכל סיבוב לוחצים **"שלוף!"** ושני הקלפים העליונים נחשפים.
3. הקלף עם **רמת הכוח הגבוהה** מנצח וחוזר לתחתית החפיסה של בעליו.
4. הקלף המפסיד **מודח מהזירה לצמיתות** — כל הפסד מקטין את החפיסה.
5. בתיקו נכנסים ל**מצב מלחמה**: כל צד מניח 2 קלפים הפוכים מהחפיסה, ואז נשלף קלף שלישי מכריע. המנצח לוקח את **כל הערימה** לחפיסה שלו.
6. המשחק נגמר כשלאחד הצדדים **נגמרו הקלפים**.

| ערפד | גונב מהיריב נקודת כוח אחת |

## עריכת חפיסה

במסך הבית יש כפתור **"ערוך חפיסה"**: אפשר לבחור עד 3 עותקים מכל מפלצת, ובסך הכל בדיוק 20 קלפים. החפיסה נשמרת בדפדפן. היריב בונה לעצמו חפיסה אקראית בעוצמה תואמת, כדי שהמשחק יישאר מאוזן.

## מבנה הקבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | כל המסכים — בית, קרב, עריכת חפיסה, אוסף המפלצות |
| `styles.css` | העיצוב וכל האנימציות |
| `monsters.js` | נתוני 20 המפלצות ומחולל הציורים ב-SVG |
| `game.js` | לוגיקת המשחק, מצב מלחמה ועורך החפיסה |
| `serve.js` | שרת סטטי קטן להרצה מקומית (לא נדרש למשחק) |

המפלצות מצוירות פרוצדורלית ב-SVG מתוך רכיבים (צורת גוף, עיניים, קרניים, פה ותוספות) — אין תלות בתמונות חיצוניות.
