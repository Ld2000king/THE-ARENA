# תמונות הקלפים

התמונות כאן הוקטנו ונדחסו מהמקור (‎~2.5MB לתמונה) לגדלים שמתאימים למשחק מובייל.
סך הכל ‎~1.2MB לכל 12 הקבצים.

אם קובץ נמחק או פגום, הקלף נופל אוטומטית חזרה למפלצת המצוירת ב-SVG
והמשחק ממשיך לעבוד.

תשעת הקלפים הנותרים משתמשים במפלצות המצוירות פרוצדורלית ב-`monsters.js`.

## כיוונון החיתוך

התמונות נחתכות למסגרת הקלף עם `object-fit: cover`. השדה `imgPos` ב-`monsters.js`
קובע איזה חלק מהתמונה יוצג — למשל `'center 18%'` מציג את החלק העליון, שם הפנים.

`dark-fist.jpg` הוא פוסטר דו-קרב עם שתי דמויות, ולכן הוא ממוסגר על `'74% 22%'`
כדי להציג את הלוחם הסגול שמימין.

## הוספת דמות חדשה

1. שמור את התמונה כאן
2. ב-`monsters.js`, הוסף לקלף את השדות `img` ו-`imgPos`
3. השאר את `power` ואת `ability` ללא שינוי כדי לא לשנות את איזון המשחק
