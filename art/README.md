# תמונות הקלפים

כאן נשמרות תמונות הדמויות שמופיעות על הקלפים.

**שמות הקבצים חייבים להיות מדויקים** — הקוד מחפש אותם לפי השם המדויק.
אם קובץ חסר, הקלף פשוט יציג את המפלצת המצוירת במקום, והמשחק ימשיך לעבוד.

## פורמט מומלץ

- `.png` או `.jpg` (אם שמרת כ-jpg, שנה את הסיומת ב-`monsters.js`)
- רצוי לדחוס לפני העלאה — תמונות מעל ~300KB יאטו את הטעינה בנייד
- התמונות נחתכות למסגרת הקלף באמצעות `object-fit: cover`.
  אפשר לכוון איזה חלק מהתמונה יוצג דרך השדה `imgPos` ב-`monsters.js`
  (למשל `'center 20%'` מציג יותר את החלק העליון, שם נמצאים בדרך כלל הפנים).
